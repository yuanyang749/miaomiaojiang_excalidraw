# Attribution

## Upstream acknowledgement

This repository builds on the upstream project:
- **Repository**: `coleam00/excalidraw-diagram-skill`
- **URL**: `https://github.com/coleam00/excalidraw-diagram-skill`

The core idea of an Excalidraw skill that generates diagrams from natural-language requests and validates output through rendering did not originate in this repository.
This project is an adaptation and extension for OpenClaw-oriented workflows.

## What this repository adds

This version adds or emphasizes the following:
- renamed skill packaging for `miaomiaojiang_excalidraw`
- OpenClaw / Telegram-friendly triggers
- slash prompt support such as `/excalidraw`, `/diagram`, `/draw`
- OpenClaw Shortcut Mode for minimal natural-language requests
- multi-theme palette presets for different content brands
- whiteboard / handout / teaching-oriented style guidance
- local integration notes in `OPENCLAW_NOTES.md`
- examples and screenshots tailored to actual OpenClaw usage
- README restructuring for public open-source presentation
